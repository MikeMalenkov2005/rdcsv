# Программа вычисления формул в CSV таблицах

В ходе выполнения тестового задания была разработана программа, считывающая
таблицу из файла в модифицированном CSV формате и расчитавающая ячейки с
формулами.

## Структура репозитория

Файлы с исходным кодом приложения на языке C находятся в подкаталоге `src`.
Файлы тестовых сценариев находятся в подкаталоге `test`.
Скрипты сборки и тестирования находятся в корне репозитория.

## Формат входного файла

Основой входного формата является CSV.

Особенности формата из условия задания:
- Первая строчка таблицы отведена под заголовки столбцов.
- Первый столбец таблицы отведён под нумерацию строк.
- Левая верхняя ячейка таблицы должна быть пустой 
- Номера строк должны быть положительными целыми числами.
- Заголовки столбцов и номера строк не должны повторяться.
- Остальные ячейки могут содержать целые числа или формулы.
- Формулы имеют следующий вид: `= ARG1 OP ARG2`.
- Аргументы в формулах могут быть целыми числами или адресами ячеек.
- В формулах могут использоваться следующие операторы: `+`, `-`, `*`, `/`.

Добавленные особенности формата:
- Заголовки столбцов и номера строк должны быть уникальными.
- В формулах может использоваться оператор остаткаа от деления (`%`).
- Знак `#` является началом комментария, который игнорируется программой.
- Пустые строки в файле игнорируются программой.
- Заголовки столбцов могут включать только латинские буквы и знак `_`.
- Пробельные символы в начале и конце ячеек игнорируются программой.
- Пробельные символы между частями формул игнорируются программой.

## Сборка приложения

Для сборки приложения, разработанного на языке ANSI C используется CMake.

Для сборки приложения после клонирования репозитория нужно перейти в корень
данного репозитория и запустить скрипт сборки: `build.bat` на Windows или 
`./build.sh` на Linux. После успешной сборки в корне репозитоя появится
исполняемый файл приложения: `rdcsv.exe` на Windows или `rdcsv` на Linux.

## Запуск программы

Запуск программы после сборки можно осуществить из командной строки:
`rdcsv.exe file.csv` на Windows или `./rdcsv file.csv` на Linux.
В примерах `file.csv` - это имя входного файла выбранного пользователем.

## Тестирование

При запуске тестирования (`test.bat` на Windows или `./test.sh` на Linux)
производится сборка (при необходимости) и проверяется работа программы на
каждом из сценариев приведённых в подкаталоге `test`: для каждого файла с
именем вида `t<N>.csv` запускается собранное приложение, результат работы
которого сравнивается с ожидаемым, представленным в соответствующих тесту
файлах `e<N>.txt` и `o<N>.txt` из подкаталога `test/expected`.

## Структура приложения

Разработанное приложение условно разделяется на 3 модуля:
1. Модуль парсинга входного файла
2. Модуль работы с таблицей
3. Модуль обработки формул

Первый модуль (`main.c` + `parse.c`) отвечает за чтение входного файла и
большую часть обработки его формата, а также содержит точку входа в программу.

Второй модуль предназначен для инициализации и работы с таблицей целых чисел.
Он также позволяет находить ячейки таблицы по заголовку столбца и номеру строки.

Третий модуль отвечает за обработку формата формул, а также за их вычисление.
